# 오삼오삼 UI/UX 분리 브랜치 구현 계획

## 목표

기존 오삼오삼 템플릿 ID, 이미지, 미리보기, 초안 생성 계약을 유지하면서 개발계획서의 8개 화면을 실제 모바일 앱 안에서 순서대로 확인할 수 있게 한다.

## 비목표

- 템플릿 데이터·이미지 교체 또는 삭제
- 서버 게시, DB, RLS, 인증, 결제, IAP 변경
- App Store/TestFlight 빌드 또는 배포
- 기존 초안 형식과 공개 링크 계약 변경

## 구현 슬라이스

1. 행사 중심 홈
   - 돌잔치·환갑/칠순·집들이를 첫 진입점으로 제공한다.
   - 기존 템플릿 컬렉션과 미리보기 이동을 그대로 사용한다.
2. 행사별 템플릿
   - 선택한 행사명을 제목과 안내 문구에 반영한다.
   - 기존 필터, 카드 탭 미리보기, 초안 생성 계약을 유지한다.
3. 8화면 UI 미리보기
   - 실제 템플릿 카탈로그와 이미지 소스를 사용한다.
   - 화면 전환은 로컬 상태만 사용하고 서버 쓰기는 실행하지 않는다.
4. 검증
   - 템플릿 자산 수와 핵심 회귀 테스트를 확인한다.
   - 타입 검사, 린트, 모바일 런타임과 스크린샷을 확인한다.
